# Quizzes — cách dùng đúng

Mục đích: **kiểm tra trí nhớ**, không phải học mới. Làm **trước** khi mở đáp án, ghi câu sai vào `progress/wrong-answers.md`.

## Quy tắc

1. Bấm giờ: **90 giây/câu**. Hết giờ thì đoán rồi đi tiếp — mô phỏng áp lực phòng thi.
2. Không tra Google, không mở note. Sai thì sai, ghi lại rồi học.
3. Mục tiêu: **≥ 80%** mỗi bộ. Dưới 80% → đọc lại note domain đó **trong ngày**, không dồn.
4. Sau 48h, làm lại **chỉ các câu đã sai** (đánh dấu trong sổ lỗi). Nếu vẫn sai → đó là lỗ hổng thật, viết flashcard mới.

## Import flashcard vào Anki

```
Anki → File → Import → chọn quizzes/flashcards.csv
→ Field separator: Comma → Fields: 3 (Front, Back, Tags)
→ Deck: AZ-104 → Import
```
